JULA

(JSON Utility Library for Ada)

Description

Jula is meant to be a simple JSON library that reads and parses JSON into appropriate Ada types and allows simple, idiomatic manipulation of that data.

For instance, with the current version of Jula you can iterate over either an array or an object in the same manner as any Ada container: for Item of .... In the same way, you can index into an array by position and into an object by key.

Appropriate constants for the null object of JSON_Null type and for the true and false objects of JSON_Boolean type.

Prerequisites

Requires Ada 2022.
