To_Wide_Wide_String

function To_Wide_Wide_String (Text : String) return Wide_Wide_String

returns a Wide_Wide_String, with appropriate conversion of UTF-8. this may be necessary after parsing, since we do not convert unicode escapes.

Parameters
Text

a JSON string, presumably with "\u" somewhere within it

Return Value

a Wide_Wide_String with any Unicode escapes encoded appropriately for display

Raised exceptions
Malformed_Unicode

when:

  • a Unicode escape string is too close to the end of the string to have a valid Unicode (\uABCD)
