To_UTF_16_String

function To_UTF_16_String
  (Object : JSON_String) return Ada.Strings.UTF_Encoding.UTF_16_Wide_String

returns a UTF16_String, with appropriate conversion of UTF-8. this may be necessary after parsing, since wedo notconvert unicode escapes.

Parameters
Object

a JSON string, presumably with "\u" somewhere within it

Return Value

aWide_Wide_Stringwith any Unicode escapes encoded appropriately for display

Raised exceptions
Malformed_Unicode

when:

  • a Unicode escape string is too close to the end of the string to have a valid Unicode (\uABCD)
