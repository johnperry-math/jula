Description

JSON Ultility Library for Ada

John Perry

CC-BY-SA-3.0

The parser follows the specification of RFC 8259. It allows some features common to real-world JSON texts that other implementations prohibit:

  • Comments beginning with //. This is allowed per section 9: A JSON parser MAY accept non-JSON forms or extensions.

  • More than one json value per text, per section 2: A JSON text is a sequence of tokens. ... Note that certain previous specifications of JSON constrained a JSON text to be an object or an array.

Caution

In order to return a JSON string as a String; the parser does not convert Unicode escape characters into UTF-8; it leaves them as \uWXYZ. There are several reasons for this, one of them being that your target may support only ASCII, Latin-1, etc. For targets capable of supporting UTF-8, use jula.literals.To_Wide_Wide_String or jula.literals.To_UTF_16_String. ...Or decode them in your own custome fashion.
