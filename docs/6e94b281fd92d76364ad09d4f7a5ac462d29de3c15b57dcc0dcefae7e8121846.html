Description

JSON Ultility Library for Ada

John Perry

CC-BY-SA-3.0

This library's main goal is an API based on Ada's standard library that allows the user to access and manipulate the object using familiar tools, rather than a completely new or slightly different API.

In particular, it is possible to:

  • access the elements of a JSON_Array or JSON_Object using the usual indexing / access techniques for vectors and maps;

  • iterate over the elements of a JSON_Array or JSON_Object using the usual iteration techniques for vectors and maps.
